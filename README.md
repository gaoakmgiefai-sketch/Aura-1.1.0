# Aura (Fabric, Minecraft 1.21.8)

Клиентский мод: KillAura (Legit / HvH), Criticals, TriggerBot, Sprint, Fullbright, HUD и ClickGUI.

* **Меню** — `Right Shift` (меняется в настройках управления).
* **KillAura** — `R` по умолчанию (можно переназначить в меню: открой модуль → Keybind).
* Конфиг сохраняется в `config/aura.json`.

Сборка: `./gradlew build` → `build/libs/aura-*.jar`. В GitHub — Actions → build → artifacts.
